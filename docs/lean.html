Bandwidth ceiling of perfectly absorbing exceptional points, checked by machine

At equal intrinsic loss L, the 90% absorption band of a perfectly absorbing exceptional point is at most 2√(2/3) L ≈ 1.633 L. The theorems below compile in Lean 4, and every change to the repository rebuilds them.

What a statement looks like

The band of the second-order EP, as written in Lean.

N2.lean · line 30
theorem band_N2 {L : ℝ} (hL : 0 < L) :
    {ω : ℝ | normSq ((ω:ℂ) ^ 2 / P2 L ω) ≤ 1 / 10}
      = Icc (-(√(2 / 3) * L)) (√(2 / 3) * L) := by
  set s := √(2 / 3) * L with hs
  -- s² = (2/3) L²
  have hs2 : s ^ 2 = 2 / 3 * L ^ 2 := by
    rw [hs, mul_pow, Real.sq_sqrt (by norm_num)]
  ext ω
  rw [r2_normSq hL]
  -- ... both directions by nlinarith

The left side is the set of real frequencies where the reflected power |r|² is at most 1/10, which is where 90% or more is absorbed.

The right side is a closed interval. Equality of the two sets means the band is exactly that interval, so its width is 2√(2/3) L.

Lean accepts the theorem only if every step checks. The build also prints the axioms each theorem uses; all 15 use only:

Check it yourself

git clone https://github.com/THUHoloLab/HoloToken.git
cd HoloToken/lean/EPAbsorber

lake build
lake env lean scripts/check_axioms.lean

Scope: the theorems are statements about the coupled-mode model of the Letter: N resonant modes with frequency-independent couplings, a passive rational scattering matrix with lossless background, intrinsic loss L = tr Γi, and the 90% band on the connected interval that contains a CPA frequency. Dimer results are stated at L = 1; B/L does not depend on scale.
