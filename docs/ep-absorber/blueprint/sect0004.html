Theorem 4.3
✓

Uses

  • Lemma 4.2

Lean declarations

  • EP.DimerBound.dimer_bound

For every \(g\ge 1\), every order-connected set \(I\subseteq \{ \omega :|r_g(\omega )|^2\le 1/10\} \) containing the CPA zero \(\sqrt{g^2-1}\) has width at most \((4/3)\sqrt{1+\sqrt{10}}\).

Proof ▶

\(|r_g|^2\le 1/10\iff |u|\le 2g/3\). For \(g\le (1+\sqrt{10})/3\) the band is \([-\sqrt{g^2-1+2g/3},\sqrt{g^2-1+2g/3}]\), increasing in \(g\); beyond, it splits into two pieces, each narrower.
