1 Setting

We consider passive absorbers described by \(N\) resonant modes coupled to external channels, with intrinsic loss \(L{\gt}0\) (the total intrinsic amplitude-decay rate of the modes). Frequencies are detunings in the same units as \(L\), so bandwidths are quoted as \(B/L\). The 90% bandwidth \(B\) is the width of the connected frequency interval that contains a coherent-perfect-absorption (CPA) frequency and on which the best input state absorbs at least 90%, i.e. \(|r(\omega )|^2\le 1/10\) for a single channel. An exceptional point (EP) of full order \(N\) is an \(N\)-mode absorber whose \(N\) CPA zeros all coalesce at one real frequency.

The main claims are:

  • every perfectly absorbing full-order EP has \(B\le 2\sqrt{2/3}\, L\approx 1.633\, L\), for every order \(N\ge 2\), and the value is attained at \(N=2\);

  • this is \(29.9\% \) of the Bode–Fano ceiling \(4\pi L/\ln 10\approx 5.458\, L\);

  • splitting the zeros already beats every perfectly absorbing EP: a two-mode dimer reaches \((4/3)\sqrt{1+\sqrt{10}}\, L\approx 2.720\, L\).
